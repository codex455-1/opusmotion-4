# The Mitrokhin Archive — a 70-second documentary short

**Deliverable:** `output/the_mitrokhin_archive.mp4`. 1080×1920 (9:16), 30 fps, H.264 High; AAC 320 kb/s at 48 kHz; mastered to −14 LUFS with a −1 dBTP ceiling; length 69.9 s.

The story: in 1992 an old man walks into a British embassy with a scruffy bag of sausages. Hidden underneath are
twelve years of hand-copied KGB secrets. MI6 gets him and his family out, and inside the notes is a name in a
quiet London suburb: Melita Norwood, the grandmother who passed Britain's atomic secrets to Moscow.
Every claim is sourced in [`docs/research.md`](docs/research.md).

No music. The soundtrack is voice-over plus frame-locked sound effects: procedurally synthesised effects, and
real recorded keystrokes for typing (capped at a natural ~11 keys/s). Text appears with soft "cream" pops.

## How it is made

| Layer | Technology |
|---|---|
| Vector art and typography | **Skia** (skia-python), F16 linear canvas; **HarfBuzz** shaping (kerning and per-glyph animation) |
| 3D | **ModernGL / GLSL 3.3** on Mesa llvmpipe (headless EGL): ~14,600 extruded OpenStreetMap buildings with procedural lit windows, 4× MSAA |
| Maps | Real geodata: BBBike/Geofabrik OSM extracts (Moscow, Greater London), Natural Earth (Europe). Baked to textures and viewed through a true 3D camera homography (pitch, yaw, dolly) |
| Post | GLSL: 6-level bloom, film halation, radial chromatic aberration, lens distortion, filmic shoulder, lift/gamma/gain grade, luma-weighted temporal grain, triangular dither (no banding in dark gradients) |
| Motion | Keyframe tracks with expo/cubic/back easing, a 180° shutter, and multi-subframe motion blur on fast moves |
| Voice | **Kokoro-82M**, `bf_emma` voice with British phonemisation and phoneme overrides for names. Each line is generated in an isolated process; the takes are ranked by **UTMOS** (a predictor trained on human naturalness ratings), and the fastest take within 0.03 MOS of the best is kept |
| Captions | **faster-whisper** word timestamps aligned to the script; two-tier kinetic captions (light italic lead line, large key line, serif-italic emphasis) |
| Sound | numpy/scipy synthesis: modal synthesis, filtered noise, convolution reverbs. Cues are registered by the scenes themselves, then sidechain-ducked under the voice, true-peak limited and loudness-normalised |

## Rebuild from scratch

```bash
.hoplite/setup.sh                                   # system EGL/Mesa + .venv (idempotent)
# geodata (≈300 MB, not committed)
mkdir -p assets/geo && cd assets/geo
for n in ne_50m_admin_0_countries ne_50m_land; do
  curl -LO https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/$n.geojson; done
curl -L -o moscow_shp.zip https://download.bbbike.org/osm/bbbike/Moscow/Moscow.osm.shp.zip
curl -L -o london_shp.zip https://download.geofabrik.de/europe/united-kingdom/england/greater-london-latest-free.shp.zip
mkdir -p moscow london && unzip -j -o moscow_shp.zip 'Moscow-shp/shape/*' -d moscow && unzip -o london_shp.zip -d london
cd ../..
.venv/bin/python tools/build_geo.py                 # bake map textures + 3D London mesh -> build/cache
.venv/bin/python tools/make_sfx.py                  # synthesise the SFX library -> audio/sfx
# typing samples (committed in audio/keys) are rebuilt from the CC0 pack with tools/make_keys.py
# (optional) regenerate narration: WITH_TTS=1 .hoplite/setup.sh, then
#   .venv-tts/bin/python tools/make_vo.py gen && .venv-tts/bin/python tools/make_vo.py pick && .venv-tts/bin/python tools/align_vo.py
#   (the pick step needs the UTMOS repo: git clone --branch v1.2.0 https://github.com/tarepan/SpeechMOS /tmp/tts/SpeechMOS)
.venv/bin/python render.py all 2                    # picture -> build/video.mp4 (2 workers)
tools/assemble.sh                                   # mix + mux -> output/the_mitrokhin_archive.mp4
```

Review helpers: `python render.py still <t>` renders a single frame, and `python render.py sheet <t0> <t1> <n> out.png` renders a contact sheet.

## Repository map

- `engine/`: core timing and easing (`core.py`), Skia helpers (`gfx.py`), HarfBuzz text (`text.py`), and GL post and 3D (`gl.py`)
- `scenes/`: `timeline.py` (narration placement and caption plan), `captions.py`, shared toolkit (`common.py`, `props.py`, `mapview.py`, `europe.py`), and eleven scenes, `s01_bag.py` … `s11_end.py`
- `tools/`: geodata bake, SFX synthesis, voice-over generation and alignment, mix, assembly
- `audio/`: narration script and recorded lines, SFX library code (WAVs are regenerated by `make_sfx.py`)
- `docs/`: [research and sources](docs/research.md), [image-generation prompts](docs/image_prompts.md), [production notes](docs/production_notes.md)
